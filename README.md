# Game-Jam

A unique time-based platformer game, built for a game jam with Godot and GDScript.

## Project

| Folder | Description |
| --- | --- |
| [`game-jam/`](./game-jam) | A unique time-based platformer game. |

## Getting Started

### Prerequisites

- [Godot Engine](https://godotengine.org/)
- [Git](https://git-scm.com/) (to clone the repository)

### Clone the repository

```bash
git clone https://github.com/GitPuller67/Game-Jam.git
cd Game-Jam
```

The default branch is `dev`.

### Open the game

Double-click `project.godot` inside the `game-jam/` directory to open the game in Godot.

## Tech

- **Engine:** Godot
- **Language:** GDScript
